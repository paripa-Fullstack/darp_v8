## 🔒 АУТЕНТИФИКАЦИЯ (5 факторов)

1. **USB серийный номер** — аппаратный токен
2. **Мастер-пароль** — BashHash-PBKDF2
3. **TOTP RFC 6238** — код из Aegis/Google Authenticator
4. **Hostname hash** — предупреждение при смене ПК
5. **Файловый хэш** — контроль целостности

### Двойной пароль
- **Пароль доступа** → нормальная работа
- **Пароль паники** → запуск + немедленное уничтожение данных (DoD 7 проходов)

## 📻 ПОЗЫВНЫЕ

Уникальный позывной генерируется из USB serial + пароль.  
Отображается в шапке приложения и в строке состояния.  
Каждый экземпляр на разной флешке = разный позывной.

## 🎙 ГОЛОСОВЫЕ СООБЩЕНИЯ

Порядок поиска аудио-бэкенда:
1. `sounddevice` (рекомендуется, pip install sounddevice)
2. `pyaudio` (требует PortAudio)
3. `winsound` (только Windows, встроен)
4. Симулированный тест-сигнал (если ничего нет)

## 🛡 ПЕСОЧНИЦА (SANDBOX)

- Файлы загружаются в RAM и шифруются Belt-128
- На диске файлы не сохраняются
- При закрытии виджета данные уничтожаются из памяти
- Поддержка: TXT, PNG, JPG, PDF (любой формат)

## 🏛 КРИПТОГРАФИЯ

| Алгоритм | Назначение |
|----------|-----------|
| Belt-128 (СТБ 34.101.31) | Шифрование всех данных |
| AES-256-GCM | Fallback при отсутствии STB |
| BashHash-256/512 (СТБ 34.101.77) | Хэширование, блокчейн |
| PBKDF2-SHA512 | Derive ключей из пароля |
| X25519 ECDH | Обмен ключами (P2P) |
| TOTP RFC 6238 | 2FA |
